Architecture Deep-Dive

Full-Stack Snake & Bounded AI Coach

Key Architectural Decisions:

  • Same-Origin Architecture: Hosted on a unified Express backend, avoiding CORS preflight round-trip latency and preserving snappy responsiveness.
  • Versioned Contract Schema: The round client delivers telemetry (duration, score, collision vectors, turn frequency) and expects a strictly validated JSON contract.
  • Deterministic Fallback Guarantee: If the AI service exceeds the 120ms latency SLA, fails schema checks, or encounters rate-limits, an embedded deterministic rule engine immediately generates gameplay feedback with zero user-perceived downtime.
  • Transactional Match Persistence: High-speed SQLite storage for session state, high-score validation, and match history without external database operational overhead.

Behavioral Model & System Flow

DOSHE (Task & Focus Concept)

Behavioral Engineering Principles:

  • Friction as an Architectural Feature: Rather than hard site-blocking that triggers user resistance and uninstall loops, DOSHE inserts micro-friction to break automated cognitive habits.
  • Micro-Commitment Activation: Lowers the psychological barrier to start by establishing a 2-minute entry commitment before extending into a focused 15-minute work sprint.
  • Anti-Dopamine Minimalism: Deliberately excludes gamified badges, level-ups, and addictive streaks that hijack attention, keeping the tool unobtrusive and intentional.
